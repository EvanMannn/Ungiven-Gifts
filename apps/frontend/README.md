# Ungiven Gifts frontend

React + TypeScript single-page app built with Vite.

```sh
npm install
npm run dev        # http://localhost:5173, proxies /api to localhost:8000
npm test           # vitest
npm run lint       # oxlint
npm run typecheck
npm run build
```

- `src/api/`: typed client for the FastAPI backend. `types.ts` mirrors the backend models.
- `src/lib/csv.ts`: imports the participant questionnaire from CSV, including Google Forms exports.
- `src/components/ui/`: shadcn/ui components, generated by `npx shadcn@latest add <name>` and edited as needed. These files belong to the repo.
- `src/pages/`: the home, create, event (participant) and admin pages.
- `src/pages/create/draft.ts`: create-form state, validation, and the API payload. This is plain TypeScript so it's easy to unit test.
